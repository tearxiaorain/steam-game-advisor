# 死亡空间TM2 / Dead Space™ 2（app_id=47780）

## 简介
在环村美国海军陆战队登上涅克罗夫特灾害发生三年后,艾萨克·克拉克从昏迷、困惑、迷茫和迷茫中醒来,在名为“飞毛腿”的空间站上醒来。探索这个世界及其零g环境,以发现关于“单位学”及其在尼克罗夫特流行病中作用的真相。

## 游玩方式
在死太空二号中,你加入死太空系统工程师艾萨克·克拉克(Isaac Clarke ) , 也就是死太空系统工程师(Systems Engineer ) , 当他醒来三年后,在USG Ishimura(Ishimura)的恐怖事件之后。 石村是一艘星际级星舰,其死机组(又称“僵尸 ” ) 被疯狂的死机重生包围着。

艾萨克在挖掘出一个被称为马克的奇特文物后,发现自己在土星周围轨道上的一个巨大的空间站“飞毛腿 ” ( Sprawl ) 。 他无法回忆起他是如何来到这里并被死去的女友妮可的疯狂幻觉所困扰的。 他必须再经历一次恶梦般的内鬼暴发,因为他正在奋力寻找答案,希望能结束所有的混乱。

关键特征 : 以360度的移动在太空中穿梭。 使用一套毁灭性工具将恐怖带入太空。 与杰弗林号一起,伊巴列·内克洛莫克进入墙壁,使用改良的遥测功能将四肢变成致命武器,埋设强大的肢解绊脚地雷,或制造船体突破,将一群怪物吸进太空。

发射艾萨克的西装助推器,让其像以前一样,在零重力下环绕发射。 探索飞毛腿的深度并遇到新的无重力战斗和基于物理学的拼图,并完全移动3600次。
